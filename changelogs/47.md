## New and improved
- Updated to Telegram 13.0.2, including Wallet, Gram transfers and collectible support
- Join requests: open a requester profile from the preview menu, or long-tap the header to open the full list
- Chat search: combine sender and media filters, and load every result in Show only matches mode
- Global plugin actions appear in the Chats three-dot menu when the navigation drawer is disabled
- Opening an `.inu.js` file explains when plugins are unavailable and links to the relevant settings
- [Messages › Message menu](tg://settings/inu/message-menu-order) shows long-tap actions clearly on narrow screens

## Fixed
- Context menus could let the list behind them scroll when opened during a drag
- Dialogs shown over stories or other sheets could lose their dismiss callback
- Voice transcriptions could disappear when a message was updated
- A folder could show all chats after the forward picker switched folders
- Expanded story reactions could remain above the app after dismissing the keyboard
- Reaction pickers outside message menus could use the wrong width
- [Messages › Pinned reactions](tg://settings/inu/pinned-reactions) displayed incorrectly with Material 3 sections
- GIF previews could crash while their animation was being recycled
- Sticker editor and other scrim menus could use colors from the wrong theme
- Web preview translations could use stale preview state
- Connection status could cover forum titles
- Inugram strings could fall back to the system language instead of the selected Telegram language

## Plugins
- ‼️ Breaking: `openChatHistory` - `load` replaced with `loadAround`, `loadMore`
- `openChatHistory`: support for reply targets, `scrollTo` and header tap handling
- `openPage` chat targets accept `messageId`
