> ‼️ This release contains an important plugins API security fix.
> It is recommended to update if you use plugins.

## New
- Updated to Telegram 13.0.3: new experimental voice recorder with noise suppression, and assorted fixes
- [Look & Feel › Customize items](tg://settings/inu/drawer-menu-order) for the navigation drawer: reorder, hide, add dividers and mini apps
- [Privacy & Security › Resolve trackable redirects](tg://settings/inu/resolve-trackable-redirects): expands share links (TikTok, SoundCloud, map links and more) when pasting and/or opening
- Web preview replacements can also be applied when pasting links ([Behavior › Web preview replacements](tg://settings/inu/web-preview-replacements))
- "Send a gift" in the profile menu, and an optional "Gift" action button ([User profile › Show "Gift" action button](tg://settings/inu/show-profile-gift-button))
- Power Saving › Effects in chats: disable animated avatars separately from video autoplay

## Improved
- Look & Feel: reworked Material 3, classic UI toggles, navigation options
- Admin log edit diffs are more easy to read
- URL cleaning prefers the bundled ruleset when it is newer than the downloaded one
- Database migrations on update now show a loading screen

## Fixed
- A sent message moves into its server order once confirmed, so the local order matches what the recipient sees
- Unread reactions: server answers that lose your own just-sent reaction are corrected from local state
- Text messages showing the "sent" tick before the server actually confirmed them
- Android 16 "expanded" dark theme force-inverting the app
- Update bar with bottom tabs disabled
- Low-resolution avatar in Settings
- Settings camera button clipped on some screen densities
- Untranslated "Chats" title in the chats list
- Reduced motion message menu glitches
- Material 3 sections styling on the "Bots with biometry access" page

## Plugins
- Plugin repositories: Telegram channels you can install plugins from and get updates through
- Plugin descriptions now support Telegram markdown
- Memory usage is shown on the plugin info page, and `inu memory` CLI command shows what running plugins hold (`-w` to keep sampling)
- `inu.sqlite`: a private sqlite database per plugin, behind the `sqlite` grant (50 MB by default, raise with e.g. `sqlite(200mb)`)
- Bundled assets: import images, fonts, audio and other binary files directly; they are read lazily and cost no JS heap. `inu.assets.get(name)` looks them up by name
- Viewing source of plugins with very long string literals is much faster
- Fixed plugins with inlined PNGs falsely flagged as obfuscated
- Fixed adaptive icons as plugin icons
